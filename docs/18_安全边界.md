# 安全边界

项目把外部内容和工具执行分成两道边界。RAG 与 MCP 结果会保留外部资料围栏，并在进入下一轮模型请求前检查可疑指令、凭据和超长内容。围栏和检查用于减少误执行，不能替代权限校验。

工具注册表现在只向模型暴露只读工具，并在执行前验证工具 JSON Schema、未声明字段和文件授权。MCP 只接入已审核的读文件能力；写入、移动、删除、目录遍历和搜索工具不进入 Agent 工具列表。MCP 服务器进程仍应在生产配置中使用 `MCP_ENABLED=false`，不需要文件能力时不启动。

文件读取必须由当前请求显式授权。Web 请求使用 `allowed_files` 字段，CLI 使用 `/files a.txt;b.md`，授权只对下一条消息有效。路径会解析到 `MCP_ALLOWED_DIR` 下的普通文件，拒绝越界路径、隐藏文件、数据库和密钥文件。模型从外部内容中生成的路径不会自动获得授权。

模型回复在释放流式片段前按轮检查长度、疑似凭据和系统提示重合。检查失败时只返回固定安全提示，不返回异常原文或模型原文。这个检查不能识别所有改写后的提示泄露，因此高敏感场景仍应采用结构化结果和服务端模板。

安全测试使用假 Provider 验证模型请求写工具时不会触发函数、未授权文件不能读取、重复工具字段和非法 JSON 不会被修复成默认参数，以及外部注入会在模型轮次前停止。所有权限判断在 Python 服务端执行，前端字段只负责提交当前请求的授权意图。
